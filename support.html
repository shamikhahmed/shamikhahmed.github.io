Support

Caps run on your device. Most issues clear with a refresh or clearing site data for that Cap. To install: open the Cap, then use Add to Home Screen / Install app (~30 seconds). Bugs go to GitHub Issues — we don’t publish personal email or phone.

Browse Caps Report a problem

How to install a Cap

  • iPhone & iPad — Open the Cap in Safari → Share → Add to Home Screen.
  • Mac — Safari: File → Add to Dock. Chrome/Edge: install icon in the address bar.
  • Android — Chrome ⋮ → Install app.

Each Cap website has an Install section with the same steps.

Common questions

Where is my data?

On your device (localStorage / IndexedDB), except DeeFoodie private beta which syncs to its private server for invited users only.

Do I need an account?

No. Caps are free to open with no signup wall.

How do I erase everything?

Open the Cap → Settings → erase / delete data (wording varies). Or clear site data for that Cap’s URL in your browser. Export a backup first if the Cap offers one.

I forgot my VaultCap PIN

The vault cannot be recovered without the PIN. Use a backup export if you made one.

DeeFoodie private beta

DeeFoodie is invite-only. There is no public install link. If you are an invited tester and need help, open a DeeFoodie issue above.
