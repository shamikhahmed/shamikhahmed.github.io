Install

Made for your lock screen.

Every Capricorn app is a Progressive Web App. Open in Safari or Chrome, then Add to Home Screen — full-screen, offline-capable, no App Store gatekeeping required.

iPhone & iPad

Safari → Share → Add to Home Screen. Works like a native app with safe-area support.

Android

Chrome → menu → Install app. Offline after first load.

Mac browser

Chrome or Safari — dock it, use it daily. No phantom notch padding on desktop.
