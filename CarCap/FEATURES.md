- Service log + reminder dates
- Fuel / odometer + basic L/100 (≥2 full tanks)
- Docs wallet (text/meta + expiry + optional photos in IndexedDB)
- Today · Coming up (30 days) + overdue banners
- Optional PWA notifications for Coming up

- ConfirmDialog (no native confirm)

- Privacy page
- PWA icons + offline SW (`carcap-v7`)
- Playwright smoke + P1 regression suite
- GitHub Pages live path for rsync

- Multi-vehicle cost reports
- Photo blobs in JSON export

## R
