    Put it on your Home Screen

    SteadyCap is a web app — installing takes a few seconds and it opens full-screen, offline.

    1. iPhone & iPad

      Open SteadyCap in Safari, tap Share, then Add to Home Screen.

    2. Mac

      In Safari choose File → Add to Dock. In Chrome or Edge, click the install icon in the address bar.

    3. Android

      In Chrome, open the ⋮ menu and tap Install app.

    Questions

    Is it free?

    Yes. Every feature, no ads, no subscriptions, no account.

    Where is my data?

    Routines, medicines, check-ins, journal and recovery timelines. It lives in this browser on this device — clearing site data erases it, so export a backup first.

    Is this medical advice?

    SteadyCap helps you keep track of routines and cravings. It isn't medical advice. Follow your doctor's or pharmacist's instructions for any medicine.

    Does it count streaks?

    No. SteadyCap tracks progress without streak pressure.

    Where is SOS?

    The centre tab, from every screen — it works offline.

    Does it work offline?

    Yes, after the first visit.
