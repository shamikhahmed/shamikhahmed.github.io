    Put it on your Home Screen

    ScentCap is a web app — installing takes a few seconds and it opens full-screen, offline.

    1. iPhone & iPad

      Open ScentCap in Safari, tap Share, then Add to Home Screen.

    2. Mac

      In Safari choose File → Add to Dock. In Chrome or Edge, click the install icon in the address bar.

    3. Android

      In Chrome, open the ⋮ menu and tap Install app.

    Questions

    Is it free?

    Yes. Every feature, no ads, no subscriptions, no account.

    Where is my data?

    Bottles, wear log, notes, layering combos and photos you add. It lives in this browser on this device — clearing site data erases it, so export a backup first.

    Is ScentCap affiliated with perfume brands?

    Brand names belong to their owners. ScentCap isn't affiliated with any fragrance house.

    How does it pick today’s scent?

    Rules that use your wardrobe, what you wore recently and — if you allow it — the weather.

    Does it work offline?

    Yes, after the first visit.
