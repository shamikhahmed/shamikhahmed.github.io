# OS Family — Design Identity

## The ONE similarity: Device Sovereignty

Every app shares exactly one rule:

> **Your data stays on your device. No mandatory account. Works offline.**

Visual expression: the **⬡ On-Device** seal on product pages and About screens — not a shared UI kit.

## What must NOT be shared

- Same card radius, nav layout, or color palette across apps
- Same font pairing (each app picks its own)
- Same dashboard grid structure
- Same empty-state copy pattern

## Hub flow (Capricorn OS)

1. **Lock screen** — time, Cap marks orbit, measured privacy line, Unlock
2. **Desktop / iPad / phone home** — widgets per Cap, dock, Spotlight (⌘K), Appearance
3. **Cap window / sheet** — pitch, features, screenshot → **Launch** (new tab, installable PWA) or **Example stories**
4. **Classic site** — about / sovereignty / pitch / investor pages for people who want a plain web page
