    Put it on your Home Screen

    MasteryCap is a web app — installing takes a few seconds and it opens full-screen, offline.

    1. iPhone & iPad

      Open MasteryCap in Safari, tap Share, then Add to Home Screen.

    2. Mac

      In Safari choose File → Add to Dock. In Chrome or Edge, click the install icon in the address bar.

    3. Android

      In Chrome, open the ⋮ menu and tap Install app.

    Questions

    Is it free?

    Yes. Every feature, no ads, no subscriptions, no account.

    Where is my data?

    Progress, quiz answers, records and certificates. It lives in this browser on this device — clearing site data erases it, so export a backup first.

    Are the certificates accredited?

    MasteryCap is educational. Nothing here is financial advice. Certificates are self-issued and not accredited.

    Which languages?

    English and Roman Urdu, switchable in every lesson.

    Does it work offline?

    Yes, after the first visit.
