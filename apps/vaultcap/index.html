    Put it on your Home Screen

    VaultCap is a web app — installing takes a few seconds and it opens full-screen, offline.

    1. iPhone & iPad

      Open VaultCap in Safari, tap Share, then Add to Home Screen.

    2. Mac

      In Safari choose File → Add to Dock. In Chrome or Edge, click the install icon in the address bar.

    3. Android

      In Chrome, open the ⋮ menu and tap Install app.

    Questions

    Is it free?

    Yes. Every feature, no ads, no subscriptions, no account.

    Where is my data?

    Accounts, cards, documents, family profiles and backups — encrypted with AES-256-GCM before they are saved. It lives in this browser on this device — clearing site data erases it, so export a backup first.

    What if I forget my PIN?

    Your vault is encrypted on this device with your PIN. If you forget it, your data can't be recovered — keep an export somewhere safe.

    Can my family use it?

    Yes — family vault profiles keep each person’s records separate and encrypted.

    Does it work offline?

    Yes, after the first visit.
