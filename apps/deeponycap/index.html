    Put it on your Home Screen

    DeePonyCap is a web app — installing takes a few seconds and it opens full-screen, offline.

    1. iPhone & iPad

      Open DeePonyCap in Safari, tap Share, then Add to Home Screen.

    2. Mac

      In Safari choose File → Add to Dock. In Chrome or Edge, click the install icon in the address bar.

    3. Android

      In Chrome, open the ⋮ menu and tap Install app.

    Questions

    Is it free?

    Yes. Every feature, no ads, no subscriptions, no account.

    Where is my data?

    Your catalog, series, shelf photos, wishlist and backups. It lives in this browser on this device — clearing site data erases it, so export a backup first.

    Is it affiliated with a toy brand?

    DeePonyCap is an independent collection tracker and isn't affiliated with or endorsed by any toy company.

    Can I export my collection?

    Yes — a full backup or a CSV, from Settings.

    Does it work offline?

    Yes, after the first visit.
