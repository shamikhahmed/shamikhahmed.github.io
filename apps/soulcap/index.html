    Put it on your Home Screen

    SoulCap is a web app — installing takes a few seconds and it opens full-screen, offline.

    1. iPhone & iPad

      Open SoulCap in Safari, tap Share, then Add to Home Screen.

    2. Mac

      In Safari choose File → Add to Dock. In Chrome or Edge, click the install icon in the address bar.

    3. Android

      In Chrome, open the ⋮ menu and tap Install app.

    Questions

    Is it free?

    Yes. Every feature, no ads, no subscriptions, no account.

    Where is my data?

    Check-ins, journal, people map, techniques and favourites. It lives in this browser on this device — clearing site data erases it, so export a backup first.

    Is SoulCap therapy?

    SoulCap offers self-help tools. It isn't therapy, medical advice, a diagnosis or a crisis service.

    What if I need help now?

    Open Help from any screen for region-aware crisis numbers. If you are in danger, call your local emergency number.

    Does it work offline?

    Yes, after the first visit.
