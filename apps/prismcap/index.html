    Put it on your Home Screen

    PrismCap is a web app — installing takes a few seconds and it opens full-screen, offline.

    1. iPhone & iPad

      Open PrismCap in Safari, tap Share, then Add to Home Screen.

    2. Mac

      In Safari choose File → Add to Dock. In Chrome or Edge, click the install icon in the address bar.

    3. Android

      In Chrome, open the ⋮ menu and tap Install app.

    Questions

    Is it free?

    Yes. Every feature, no ads, no subscriptions, no account.

    Where is my data?

    Players, scores, XP, achievements and saved games. It lives in this browser on this device — clearing site data erases it, so export a backup first.

    How do we play?

    Pick a game, add players, then pass the phone around. Hidden-role games only show each player their own screen.

    Does it need Wi-Fi?

    No. Every game works offline once the app has loaded.

    Does it work offline?

    Yes, after the first visit.
