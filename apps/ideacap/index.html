FAQ

Where is my data?

On your device (localStorage / IndexedDB), except DeeFoodie private beta which syncs to its private server for invited users only.

How do I erase everything?

Open the app → Settings → erase / delete data (wording varies by Cap). Or clear site data for that Cap’s URL in your browser.

DeeFoodie private beta

DeeFoodie is invite-only. There is no public install link. If you are an invited tester and need help, open a DeeFoodie issue above.
