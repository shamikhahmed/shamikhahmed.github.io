    Put it on your Home Screen

    TravelCap is a web app — installing takes a few seconds and it opens full-screen, offline.

    1. iPhone & iPad

      Open TravelCap in Safari, tap Share, then Add to Home Screen.

    2. Mac

      In Safari choose File → Add to Dock. In Chrome or Edge, click the install icon in the address bar.

    3. Android

      In Chrome, open the ⋮ menu and tap Install app.

    Questions

    Is it free?

    Yes. Every feature, no ads, no subscriptions, no account.

    Where is my data?

    Trips, tickets, documents, budgets, packing lists and memories. It lives in this browser on this device — clearing site data erases it, so export a backup first.

    Can I book flights in TravelCap?

    No. TravelCap organises trips you have booked. Always check official sources for visas, entry rules and flight times.

    Can I lock my documents?

    Yes — an optional app lock protects your travel documents.

    Does it work offline?

    Your trips and documents do. Search, maps and weather need a connection.
