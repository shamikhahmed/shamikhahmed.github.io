    Put it on your Home Screen

    IdeaCap is a web app — installing takes a few seconds and it opens full-screen, offline.

    1. iPhone & iPad

      Open IdeaCap in Safari, tap Share, then Add to Home Screen.

    2. Mac

      In Safari choose File → Add to Dock. In Chrome or Edge, click the install icon in the address bar.

    3. Android

      In Chrome, open the ⋮ menu and tap Install app.

    Questions

    Is it free?

    Yes. Every feature, no ads, no subscriptions, no account.

    Where is my data?

    Notes, recordings, tags, summaries, folders and reminders. It lives in this browser on this device — clearing site data erases it, so export a backup first.

    Is my voice sent to the cloud?

    Not by IdeaCap. Native apps transcribe on the device; on the web you type your idea.

    Can I organise ideas?

    Yes — folders, tags and soft reminders.

    Does it work offline?

    Yes, after the first visit.
