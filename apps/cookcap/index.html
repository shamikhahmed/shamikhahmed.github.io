    Put it on your Home Screen

    CookCap is a web app — installing takes a few seconds and it opens full-screen, offline.

    1. iPhone & iPad

      Open CookCap in Safari, tap Share, then Add to Home Screen.

    2. Mac

      In Safari choose File → Add to Dock. In Chrome or Edge, click the install icon in the address bar.

    3. Android

      In Chrome, open the ⋮ menu and tap Install app.

    Questions

    Is it free?

    Yes. Every feature, no ads, no subscriptions, no account.

    Where is my data?

    Your cookbook, favourites, notes, shopping list, meal plan and profiles. It lives in this browser on this device — clearing site data erases it, so export a backup first.

    Are nutrition values exact?

    Nutrition values are estimates.

    Can I add our own recipes?

    Yes — import or add family recipes, and they stay in your book on this device.

    Does it work offline?

    Yes, after the first visit.
