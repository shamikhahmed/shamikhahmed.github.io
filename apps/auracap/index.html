    Put it on your Home Screen

    AuraCap is a web app — installing takes a few seconds and it opens full-screen, offline.

    1. iPhone & iPad

      Open AuraCap in Safari, tap Share, then Add to Home Screen.

    2. Mac

      In Safari choose File → Add to Dock. In Chrome or Edge, click the install icon in the address bar.

    3. Android

      In Chrome, open the ⋮ menu and tap Install app.

    Questions

    Is it free?

    Yes. Every feature, no ads, no subscriptions, no account.

    Where is my data?

    Your imported app list, profiles, scores and layouts. It lives in this browser on this device — clearing site data erases it, so export a backup first.

    Does AuraCap read my iPhone?

    No. You import an app list yourself, and nothing is uploaded.

    Is AuraCap made by Apple?

    Apple, iPhone, iPad and Mac are trademarks of Apple Inc. AuraCap isn't affiliated with Apple.

    Does it work offline?

    Yes, after the first visit.
