TravelCap privacy

Last updated: 14 October 2026

TravelCap is an offline-first travel organizer. Trip data, packing lists, memories and documents are stored on your device (IndexedDB). There is no TravelCap account and no TravelCap analytics.

On this device

  • IndexedDB / Dexie — trips, transit, packing, party, memories (including photo blobs), preferences.
  • Service worker (optional) — when the browser allows it, TravelCap registers a service worker under this app’s path to cache the app shell for offline use. Registration is skipped or fails safely if Service Workers are unavailable or blocked; the app still works online. Cache names follow the release SW tag (G-8).
  • App lock (optional) — passcode can protect documents on this device. Forgotten passcodes cannot unlock protected data — export a backup first.
  • OCR (optional) — Tesseract runs on-device only when you tap Scan; document images stay local.

Optional network destinations

These run only when you use the related feature. Providers see normal request metadata (IP, user agent).

  • Nominatim (nominatim.openstreetmap.org) — place, hotel, and airport search / geocoding.
  • OpenStreetMap tiles (*.tile.openstreetmap.org) — map imagery on the passport world map.
  • REST Countries (restcountries.com) — country reference data.
  • Open-Meteo (api.open-meteo.com) — weather for packing hints.
  • Frankfurter (api.frankfurter.app) — currency conversion rates.
  • AviationStack (api.aviationstack.com) — optional flight lookup. You may paste your own API key in Settings; it stays on your device for static hosting. Many free-tier plans block browser CORS or HTTPS — TravelCap shows a plain error and offers manual entry. Non-export local builds may use a server proxy with AVIATIONSTACK_ACCESS_KEY in .env.local (key never shipped to the static Pages build).

There is no Capricorn “sync server” for TravelCap trip data. Static GitHub Pages hosting has no flight API backend.

Disclaimer

TravelCap helps you organize trips and documents. It is not a substitute for official travel advice, visas, or airline information. Verify times and requirements with carriers and authorities. Explore catalogs are curated on-device references — not live booking inventories.
