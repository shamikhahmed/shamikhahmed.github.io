Shamikh Ahmed OS Portfolio — Enterprise Demo Guide

Goal: Repeatable 30-minute investor/enterprise walkthrough across all 6 apps — seed data via UI, no code edits.

Last verified: June 10, 2026 (Phase 3)

---

Prerequisites (5 min)

1. Mac with Chrome or Safari; stable network for first PWA load.

2. Clone portfolio at /Users/shamikhahmed/Desktop/Projects/ (or use GitHub Pages live URLs).

3. One-time Playwright browsers: npx playwright install chromium (in any app dir).

4. Optional local serve (faster): from each app folder, npx serve -l . (ports 8765–8770).

FAQ (enterprise)

Is data encrypted?

VaultOS: AES-256-GCM with PIN. Other apps: localStorage/IndexedDB on device — protect device passcode and exports.

Is there telemetry?

No analytics SDKs in any of the six apps.

Medical device?

No. DisciplineOS supports recovery workflows; SOS is not clinical care.

Investment advice?

No. StundsOS is a personal ledger; Zakat is estimate-only.

AI / LLM?

VaultOS optional LLM import via proxy. FitnessOS Smart Coach is rule-based. Others: no LLM.

Offline?

All six PWAs work offline after first load.
